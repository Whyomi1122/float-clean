通话环境音 · 音源放置说明
========================

把音频放在本目录，文件名必须与下面一致（mp3，30~60 秒无缝循环，单个 <500KB）：

  rain.mp3      雨夜窗边：雨声 + 隐约车流
  cafe.mp3      咖啡厅：低嘈人声 + 杯碟轻响
  street.mp3    夜晚街道：人流 + 远处车声
  car.mp3       车内：引擎低鸣 + 路噪
  beach.mp3     海边：浪声 + 风
  bedroom.mp3   安静卧室：风扇/空调底噪（近似无声）
  station.mp3   车站/机场：广播 + 脚步人流

说明：
- 想改场景名，改 lib/call-ambience.ts 里的 label。
- 文件缺失时该场景静音，不会报错、不影响通话。
- 循环要求：首尾电平接近，否则会有"咔"的一下。
- 建议响度：峰值 -12dB 左右，环境音默认音量 35% 才不至于盖住人声。
- 用户选择与音量存在浏览器 localStorage（ai_phone_call_ambience_v1），跨通话记住。
